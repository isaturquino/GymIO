# 👨🏻‍💻 Relatório Individual – Emanuel

**Função:** Desenvolvedor Frontend

## 1. Atividades Realizadas no Projeto

Durante o terceiro bimestre, atuei principalmente na correção e integração das telas de **Dashboard** e **Gestão de Alunos**, buscando garantir que as informações apresentadas no frontend estivessem sincronizadas com os dados do sistema.

No **Dashboard**, trabalhei na sincronização dos dados, corrigindo os cards e indicadores para que apresentassem informações atualizadas conforme os registros existentes no sistema. Também realizei testes de integração com o banco de dados para verificar se os valores exibidos correspondiam aos dados reais.

Na **Gestão de Alunos**, fiquei responsável por fazer os cards funcionarem corretamente e revisar as funcionalidades presentes na tabela. Foram realizados ajustes nos botões de busca, filtros, edição, visualização e exclusão dos registros.

Também trabalhei na organização da tabela para que a **rolagem acontecesse somente dentro da tabela**, evitando que a página inteira apresentasse rolagem desnecessária. Além disso, foram realizados ajustes na integração com a API para garantir o funcionamento das operações.

## 2. Conhecimentos Adquiridos

Durante essa etapa, aprofundei meus conhecimentos em **React, integração com APIs e manipulação de dados no frontend**.

Também adquiri mais experiência com:

- Sincronização de dados;
- Consumo de APIs;
- Desenvolvimento de tabelas;
- Busca e filtros;
- Manipulação de estados;
- Responsividade;
- Organização da interface.

O trabalho também contribuiu para melhorar minha capacidade de identificar problemas de integração entre frontend, backend e banco de dados.

## 3. Dificuldades Encontradas

A principal dificuldade foi garantir que os dados apresentados nas telas estivessem realmente sincronizados com o backend.

Também foram encontrados problemas relacionados aos botões da tabela, filtros, edição, visualização e exclusão dos alunos.

Outro desafio foi ajustar a rolagem da tabela sem prejudicar o restante da página.

## 4. Como as Dificuldades Foram Resolvidas

As dificuldades foram solucionadas por meio de testes das requisições realizadas pelo frontend e verificações dos dados retornados pela API.

Também foram revisados os componentes das tabelas e os eventos dos botões, realizando ajustes nas funções de busca, edição, visualização e exclusão.

Foram realizados ajustes no CSS para limitar a rolagem à tabela e manter a página organizada.

## 5. Considerações Finais

As atividades realizadas contribuíram para meu desenvolvimento na área de frontend, principalmente na integração com APIs e na criação de interfaces mais funcionais.

A experiência também permitiu compreender melhor a importância da sincronização entre frontend, backend e banco de dados para garantir o funcionamento correto de um sistema administrativo como o GymIO.
